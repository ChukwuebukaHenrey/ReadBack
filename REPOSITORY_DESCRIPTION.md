# Repository description

An accessibility-first Solana Devnet gateway with keyboard and screen-reader navigation, clear transaction readbacks, and human-approved payments.

## About Readback

Readback explores a clearer way to interact with Web3. A React and TypeScript interface provides deterministic navigation, plain-language learning, and a server-side Groq intent interpreter. The planned payment flow uses a disposable local Devnet wallet, independently verified saved contacts, exact transaction review, and explicit human approval. AI never signs or authorizes a transaction.

Built for a Solana hackathon. Devnet test funds only. Wallet and payment milestones are in progress; accessibility validation with assistive technology remains pending.
